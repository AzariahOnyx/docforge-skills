# Mark a task Done on one track

Finish one workstream on a task while leaving its other tracks unchanged.

## Before you begin

- Use a project with Tracks enabled.
- Be a team member with access to the task. Guests have the same track permissions as members on projects they can access.
- Have the task's details open. The task must be Open and already In Progress on the track you want to finish.

## Steps

1. Open the **Tracks** pill in the task's details.
2. Find the track whose status is In Progress.
3. Select **Mark Done** for that track.

## Expected result

The track's status in the pill changes to Done. The task's statuses on other tracks stay the same. Marking a track Done is separate from completing the whole task.

## Resume work on the track

To resume work while the task is open, select **Mark Pending** for the Done track in the **Tracks** pill. Its status returns to In Progress.

## Working offline

**Mark Done** and **Mark Pending** work offline. Changes queue locally and reconcile when you reconnect.

> **Important:** If the track was deleted online before a queued membership change syncs, the change is dropped silently and does not recreate the track.

For the broader task and track model, see [Follow parallel work with Tracks](../feature/feature-guide.md).
