# Track parallel progress on a single task

Tracks gives each workstream its own progress on the same task.

- **Independent progress:** Keep a task on several tracks at once. Marking it Done on one track leaves the others unchanged.
- **A complete task view:** Open the **Tracks** pill in task details to see every project track and the task's status on each.

Learn how to [follow parallel work with Tracks](../feature/feature-guide.md).
