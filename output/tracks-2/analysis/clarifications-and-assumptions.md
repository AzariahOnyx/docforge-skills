## Editorial assumptions

- **ASSUMPTION A01:** The three requested audiences can be served by one concise guide each, without extra product articles. Evidence: assignment p. 1; scope bounded by existing demo workflow. No claim that existing help content exists.
- **ASSUMPTION A02:** A how-to may start from an accessible open task already In Progress on a track. This is an explicit reader prerequisite supported by pp. 4–6, not a claim that users receive preconfigured tracks.
- **ASSUMPTION A03:** “Tracks” is the feature name and “task” is the preferred object term for drafting (pp. 2–6); unclear navigation labels are avoided pending Q09.

C23 is a strong model inference, not an explicit sentence defining Start’s destination. Prefer the entirely explicit Mark Done / Mark Pending task for procedural certainty; do not present inferred Start transition as independently verified implementation.
