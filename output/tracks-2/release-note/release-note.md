# Track progress independently across workstreams

Tracks introduces parallel workstream progress for a single Tasket task, so each discipline can record where its work stands.

- **Separate progress on the same task.** Start a task on several project tracks and mark it Done on one without changing its status on the others.
- **All track statuses in task details.** Open the **Tracks** pill to see every project track and whether the task is Not started, In Progress or Done on each.

Learn how [Tracks organizes parallel work](../feature/feature-guide.md), including access, lifecycle and offline behavior.
