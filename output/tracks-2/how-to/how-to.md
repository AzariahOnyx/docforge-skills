# View all of a task's track statuses

Use the Tracks pill to see where a task stands across every track in its project.

## Before you begin

You need access to the task, and Tracks must be enabled for its project. The pill is not shown when Tracks is switched off. You can view retained track statuses on a closed task without reopening it.

## Steps

1. Open the task's detail view.
2. Open the **Tracks** pill.
3. Read the status beside each project track: **Not started**, **In Progress**, or **Done**.

## Expected result

You see every track in the project and the task's status on each in one view. The pill also shows the number of Done tracks out of all available tracks for the task.

For more about board visibility and track behavior, see [Tracks](../feature/feature-guide.md).
