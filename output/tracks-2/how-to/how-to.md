# Mark a task done on one track

Use this procedure when one workstream is finished and you want to record its progress independently of the task's other tracks.

## Before you begin

- Start with an open task that is In Progress on the track you want to finish, in a project with Tracks enabled.
- You must be a member with access to the task. Guests have the same track permissions as members on projects they can access.

## Steps

1. Open the task's details.
2. Open the **Tracks** pill to see the task's status on each project track.
3. For the track you have finished, select **Mark Done**.

## Expected result

The selected track shows Done in the pill. While the task is open, it appears in that track's Done section on the board. Its status on other tracks is unchanged. Marking a track Done is separate from completing the task itself.

## Resume work on the same track

In the **Tracks** pill, select **Mark Pending** for that track. Its status returns to In Progress.

For lifecycle and offline behavior, see [Track one task across parallel workstreams](../feature/feature-guide.md).
