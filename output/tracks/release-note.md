# Tracks: follow one task across workstreams

Tracks let a project team start the same task in multiple workstreams and follow its progress separately in each one.

- The new **Tracks** tab organizes open tasks by track and by **In Progress** or **Done** status.
- A task's **Tracks pill** shows its status across the project's tracks in one place.
- Team members can start tasks on tracks, mark track work Done, and return it to In Progress without changing other tracks.
- Track memberships and statuses remain with a task when it is closed and return to the board when the task is reopened.
- **Start**, **Mark Done**, and **Mark Pending** can be used offline; changes reconcile on reconnect.
