# Coordinate task progress across parallel tracks

Tracks adds a way to manage parallel workstreams for the same task while keeping progress independent in each track.

- **Track progress independently.** Mark a task Done on one track without changing its progress on other tracks or completing the task itself.
- **Start selected tasks across tracks.** Select multiple tasks and start them across other tracks in one action.
- **Review progress in one place.** Use the **Tracks** pill on a task to see its status across every track in the project.

For details, see [Coordinate parallel work with Tracks](../feature/feature-guide.md).
