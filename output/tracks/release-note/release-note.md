



# Track progress across parallel workstreams

With Tracks, you can coordinate several workstreams on one task while keeping each track's progress independent.

- **Update progress per track.** Mark work Done on one track without changing its status on other tracks or completing the task itself.
- **Start selected tasks across other tracks.** Use multi-selection to start tasks across tracks in one action.
- **See the full picture from a task.** Open the **Tracks** pill to view the task's status on every project track, including retained statuses when the task is closed.

Learn how to [coordinate parallel work with Tracks](../feature/feature-guide.md).
