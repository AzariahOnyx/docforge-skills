# Mark a task Done on one track

Record completed work on one track without changing the task's progress on its other tracks.

## Before you begin

- Tracks must be enabled for the project.
- You must be a member with access to the project and task. Guests have the same track permissions as members on projects they can access.
- The task must be open and already **In Progress** on the track you want to update.

## Steps

1. Open the project's **Tracks** tab.
2. Find the task in the **In Progress** section of the track you want to update.
3. Select **Mark Done** for that task.

## Expected result

The task is **Done** on the selected track and appears in that column's **Done** section. Its other tracks are unaffected, and marking it Done on a track does not complete the task itself.

If this was the last In Progress task in the column, that section is empty and the column counter updates.

## Return the work to In Progress

If work on that track needs to resume, select **Mark Pending** for the task in the column's **Done** section. The task returns to **In Progress** on that track. A Done task cannot be stopped.

For the relationship between task status and track progress, see [Coordinate parallel work with Tracks](../feature/feature-guide.md).
