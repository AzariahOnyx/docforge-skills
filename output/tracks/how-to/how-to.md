# Mark a task Done on one track

Update a task's progress on one track without changing its progress on other tracks or completing the task itself.

## Before you begin

- Tracks must be enabled for the project.
- You must have access to the project and task.
- The task must be open and **In Progress** on the track you want to update.

## Steps

1. Open the project's **Tracks** tab.
2. In the track you want to update, find the task under **In Progress**.
3. Select **Mark Done**.

## Expected result

The task moves to **Done** on the selected track. Its progress on other tracks does not change, and the task itself remains separate from its per-track progress.

If no other tasks are In Progress in that column, the **In Progress** section becomes empty and the column counter updates.

## Resume work on the track

To resume work, find the task under **Done** and select **Mark Pending**. The task returns to **In Progress** on that track.

For more information about task and track states, see [Coordinate parallel work with Tracks](../feature/feature-guide.md).
